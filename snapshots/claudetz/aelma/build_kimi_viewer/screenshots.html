AELMA Alerts UI - Screenshots & Examples

Overview: The Alerts UI provides real-time visualization of WatcherRegistry actions from the AELMA twin core, displaying color-coded alerts with priority levels, 3D visual indicators, and quick action buttons for safety-critical vessel operations.

Key Features

🎨 Color-Coded Alerts

Critical (≥0.9): Red, pulsing
High (0.7-0.9): Yellow
Medium (0.4-0.7): Green
Low (<0.4): Blue

🎯 3D Indicators

Critical: Glowing sphere + floating label
Others: Ring marker at vessel
Real-time position tracking

⚡ Quick Actions

Haul gear, drop anchor
Confirmation dialogs
WebSocket integration

📜 Alert History

Timestamped log (max 20)
Priority color coding
> Persistent across sessions

Default Watcher Rules

Built-in safety alerts in twin core

GROUNDING_RISK

Trigger: depth < 1.0m
Priority: 0.95 (critical)
Cooldown: 15s

SHALLOW_WATER

Trigger: depth < 2.0m
Priority: 0.85 (high)
Cooldown: 30s

ENGINE_OVERHEAT

Trigger: engine_temp > 90°C
Priority: 0.92 (critical)
Cooldown: 20s
